## 颜色（用户可见产物必须用）

| Token | Hex | 依据 |
|---|---|---|
| `--brand` / 主色 | `#FF8700` | 官网 CSS 高频品牌色 |
| `--brand-strong` | `#FF9100` | logo 像素主色均值 |
| `--ink` | `#182134` | 官网深色正文/底 |
| `--ink-soft` | `#0D131A` | 官网更深底 |
| `--muted` | `#595959` | 官网次级灰 |
| `--surface` | `#FFFDF8` | 卡片浅底（偏暖，贴近品牌橙） |

图表主系列、KPI 强调色、链接色：`--brand`（`#FF8700`）。  
禁止再使用默认青绿（`#0f766e`）作为主强调色。
