# 错题：〈一句话，扫目录就能懂〉

| 元数据 | 内容 |
|---|---|
| 日期 | YYYY-MM-DD |
| 标签 | 从 README 推荐标签里选 1–4 个；可选 `sev-*` |
| 环境 | 本机 demo／云端／客户…（可写版本或 gitSha） |
| 相关 | Spec／Plan／commit／issue 链接（可空） |
| 状态 | `open`（后续动作未闭合）／`mitigated`／`closed` |

## 1. 症状与影响

- 谁在什么页面／路径上看到什么
- 影响面（本机／云端／客户；是否主视觉／主路径）

## 2. 复现要点

最短步骤或判定条件（不必贴大段日志）。

## 3. 根因

分层写清（合同／实现／数据／环境）。能指到提交或 SQL／配置条件就指到。

## 4. 为何漏检

缺哪道门禁、默认筛掉了什么证据、单测绿但部署空、浏览器未走查等。

## 5. 举一反三

2–5 条可迁移规则（给人和 Agent）。写「下次同类改动必须…」，不要写空话。

## 6. 后续动作

| 动作 | 状态 | 说明 |
|---|---|---|
| … | 未开／进行中／完成 | 登记 ≠ 授权开工 |

## 7. 证据指针

相对路径或短摘录即可；大文件放 `inbox/` 并在此引用。
