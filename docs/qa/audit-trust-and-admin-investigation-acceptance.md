## 1 执行层级和状态

- C：纯合同/单元，含合成历史投影、分类、CSV和哈希校验。
- I：真实Lucy HTTP/Proxy/安全账本集成，隔离临时库，可接mock upstream。不能宣称真实Agent或真实业务DB已验证。
- B：真实桌面浏览器操作，隔离合成fixture，1440×900和1280×800；截图、点击/导航和API对账共同举证。
- A：真实受控客户端，经Lucy到测试数据服务并返回结果；明确客户端/模型、版本及其采集范围。curl或发送器模拟不属于A。
- O：隔离环境的故障、重启、保留/恢复或代理边界演练。
- V：离线证据及篡改反向校验。

状态仅为not_run/passed/failed/blocked；required缺环境为blocked，不能记skip或改成非required。实现状态和测试状态分开。本轮只交付文档，所有EA默认not_run。

Lucy本体范围required为EA-01至24、EA-30至36，以及EA-28关于未接入者可见性的本体断言。受控客户端范围再要求EA-25至29。EA-12的外部子场景仅在冻结客户profile要求时required；本体仍必须准确说明本地证据的信任范围。一次功能通过不能消除其他现有安全/发布门禁中的blocked。

EA-28、EA-31同时包含本体与受控客户端子场景：本体按I/B验证自己的控制与未知状态；真实A层的去向观察和客户端尝试链在受控客户端范围required。EA-34分别记录本地与目标规格，不用本地通过代替目标环境通过。T00将这些子场景显式登记在case-map，不能在运行后删减required。

## 3 历史样本与新版本运行的区别

历史105/119数据证明导出当时的事实，不能通过重写原始包制造新系统已经正确。测试夹具应分别保留原始错误关联和追加修订后的有效视图，附associationRuleVersion/classificationVersion。

合成fixture必须包含同名表跨连接、不同权限角色、同RPC ID跨会话、异步完成、客户端未到达请求及代理头负例；金额和业务文本用生成值替代。原始用户文件只在本机只读核对，不打入客户镜像、Git或公开CI制品。

## 4 每批交付证据格式

Claude可采用现有runner证据形状并增加下列字段，不另造竞争的发布verifier。没有现成执行器时先在T00映射到已有三类测试集，不能为了本主题另建第四类E2E体系。

```json
{
  "taskId": "T01",
  "runId": "audit-trust-<time>-<id>",
  "candidate": {"commit": "<sha>", "imageDigest": null, "configDigest": "<safe-digest>"},
  "scope": "lucy-core",
  "environment": {"layer": "integration", "architecture": "arm64", "syntheticData": true},
  "cases": [{"id": "EA-02", "status": "not_run", "evidenceRefs": [], "reason": "pending"}],
  "commands": [],
  "uncovered": [],
  "review": {"reviewer": "Codex", "status": "pending"}
}
```

evidenceRefs定位脱敏命令输出、断言结果、HTTP/客户端事件或浏览器操作证据。引用文件摘要保护本次对账，但不自动提供独立可信来源。真实执行后填入真实值，不预填passed或伪造imageDigest。

## 5 Codex独立评审步骤

1. 确认候选diff和用户已有修改归属；查Spec修订表，确保无旧120秒规则、旧工具计数仍被新代码调用。
2. 审阅准入关联冻结、跨身份/会话约束、错误分支、先持久后释放、导出固定快照、隐私及迁移。对照上表逐项查看实际测试，不以测试名推断覆盖。
3. 独立复跑该批关键负例及一条成功链；T05检查真实桌面操作；T06检查真实适配器而非仅发送器；外部设施required时核对独立回执。
4. 检查证据绑定版本、序列范围、筛选和算法版本；确认不把单元/历史样本/本地arm64替代真实客户端或目标K8s。
5. 给出passed、需修改、证据不足或范围blocked，并指出阻断EA与复验入口。全部required关闭后才给本功能所选范围通过；客户发布另走既有门禁。
