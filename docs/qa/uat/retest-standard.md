# UAT 独立复测标准

由套件提供一份可执行的交接手册。复测者只需要仓库、手册中列出的工具和可重建的测试环境。首个实例见[核心可用性 UAT 复测手册](suites/core-availability/retest.md)。状态定义沿用 [UAT 约定](CONVENTIONS.md#判定)，正式跑次仍登记在[测试台](INDEX.md)。

## 套件交接清单

| 交接项 | 最低要求 |
|---|---|
| 范围 | 套件与用例 ID，映射到已有合同。逐档说明必做项、可选项、合法用户能完成的任务，以及各档结果可以支持的结论。 |
| 输入 | 冻结源码版本、候选镜像标识、测试依赖标识、环境资源、夹具生成方式、独立预期结果和运行参数。通过本机合成数据与隔离资源提供自包含输入。 |
| 执行 | 给同事和 Agent 复用同一个命令入口。记录环境预检、短校准、正式档位、停止与清理。让自动化入口使用真实接口和真实下游任务。 |
| 证据 | 保存实际身份、每个请求的计划与终态、业务结果和耗时、变更与恢复回执、资源清理结果，以及可离线核对的证据清单。 |
| 判定 | 提供只读离线核验入口，输出可机读的判定。运行器与核验器分开。用户路径错误、测程或采集错误、明确未覆盖的项分别记录。 |
| 交接验收 | 第二执行者从空输出目录按手册复跑。另一次离线核验直接读取产物，独立重算判定、分母和失败分类。重复运行产生的新样本各自判定。 |

用例记录至少填写 **ID、用户步骤、前置与夹具、固定阈值、独立预期结果、必做或可选、证据文件、结果**。采用真实 Agent 客户端或 WebUI 时，另记客户端版本和用户可见计时。已有浏览器要求见 [UAT 约定](CONVENTIONS.md#webui浏览器计时强制)。

## 复测回报

填写 **套件／档位、候选与依赖标识、实际命令、用例逐项结果、核验器出口、原始证据指针、GAP 或失败域**。可选项缺失需要明确影响范围。环境预检未通过登记 `BLOCKED`，正式必做项失败登记 `FAIL`。保留失败跑次，后续修复用新目录记录。
