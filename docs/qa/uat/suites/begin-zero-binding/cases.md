## 公共执行和判定

- 路径／组合以 [fixtures 单一覆盖矩阵](fixtures.md#统一路径与覆盖矩阵) M01–M10 为准；N＝不 begin，B＝正常新 begin，D＝非阻断降级（G1／G2／G5 按行指定）。每例独立建立／解除故障，不继承前例未知状态。
- B 必须非 isError、recorded=true、真实 ID；G1 必须非阻断、recorded=false、turnId=null；G2／G5 必须非阻断、recorded=true、实际 ID、questionState=record_only、budgetStatus=unchanged，不能用一个 recorded=false 代替全部降级。
- HTTP 200 不代表工具成功；每条 begin 与 query 分别留原响应和断言，事实值须与独立数据库 oracle 相符。budgetStatus、有效 turn、round／window／calls／busyMs／续查和强制快照均前后读回；B／D 另核对 operationId、`question_state`、有效指针与 `question_begin_commit` 回执，record_only 不得进入有效指针。
- 禁止管理员 Token 问数、补空注册表、补 reindex、删凭据或重启修绿；真实重启仅 11。07 的独立有绑定正式控制入口不是零绑定修复步骤。
- 基线合法、产品可达却因 begin 新增拒绝／等待／人工要求为 FAIL；缺环境／客户端／可控故障或 OQ 未冻结为 BLOCKED。G3 等基线自身的安全拒绝独立判定，不能算降级成交或用关预算回避。
- 故障影响共享物理存储时须证明具体格可隔离；做不到即 BLOCKED，不降为模拟返回。每例清理后读回健康状态；失败保留正式脱敏证据，缺失数据不倒推成功。

## UAT-ZB-06 — 轮次／权限／预算 M04

**前置**：A／B／C、D1–D4 独立身份控制；预算启用，额度足够，实际阈值固定。每分支记录 round／window／有效 turn／旧轮归档及已用额度。

**步骤与独立断言**：

1. N、MCP 断开重连、D(G1)、G2／G5 各在预耗预算后执行：不产生新轮次／窗口，不清零计数或续查，query 仍正常记账；下一次合法 B 成交。
2. 合法第一问题 B 后做部分消费，再发真正第二个问题 B：按冻结 D6 原子取代有效归属、推进 round／window、归档旧耗时，第二问题正常成交；不能错误要求保留第一问题计数。
3. 再次独立发相同文本、相同 JSON-RPC id 的 begin：不得用文本／时间／RPC id 猜客户端重放；无持久凭据时成功仍按独立新 B。响应／指导不得声称已支持跨重连协议幂等。
4. 对同一个**已受理服务端操作**重放内部提交恢复，验证复用同一 operationId／turnId 和 `question_begin_commit` 回执、只生效一次；F 做确定性持久化边界，R 保存进程内实际持久化恢复读回（不停止服务；系统重启仅 11）；不能以第三步的独立请求代替。
5. G3：真实预算存储整体不可用，分别 N query、begin、后续 query；保留真实预算不可用拒绝及实际 turn 是否落库。恢复后预算读回并合法成交，不清空预算恢复。
6. A／B／C 各跑 N／B／D(G1) 的适用路径：A＝4／100、B＝2／30；C 的 begin 真实未授权，拒绝后 N 仍成交。C 不伪构成功 B／D。
7. D1 过期、D2 吊销、D3 Agent disabled、D4 global deny 分别发 begin／query：对应既有拒绝有效且未执行；解除 D3／D4 的测试控制后同一合法 Token 成交；D1／D2 不复活失效凭据，换合法控制 Token 核对恢复。

**期望／证据**：真实预算耗尽仍依既有续查合同，不关闭预算；G3 不算 begin 增量阻断，不冒称非阻断成功。保存每分支独立前后状态、事实／拒绝及未执行证据。

**清理**：解除每个局部故障及角色／Agent 控制并读回，恢复隔离测试预算夹具，不复用上一分支未知状态。

## UAT-ZB-08 — 审计与画像补偿 M06

**前置**：I0／A；现有只读日志／审计／版本入口；G1／G2／G5 和 G4 独立可控。本例自建故障，不引用 05 遗留。
