## 使用规则

1. 关闭粒度是**条目**，不是整份报告。每条须有「证据路径」和「判定人」，空白即未关闭。
2. 关闭 ≠ UAT PASS ≠ 可上线。UAT 结果只以 [`INDEX.md`](../../INDEX.md) 为准，本表只勾连。
3. 改运行代码须先有该条目的终稿确权、决策闭合和委托人开发授权。本表 **A、B 区在授权前只能做诊断，不能做修复**。
4. 全部证据来自同一类候选：`gitDirty=false`，镜像 digest 已记录，真实 KTX，合成数据源。禁止桩服务、手工改状态、手工重启冒充自愈。
5. 涉及 WebUI 用户可见面的条目，须真实前台浏览器加即时计时，与 API 耗时分列。纯 MCP 条目不强制浏览器。
6. 主路径可用性：每条「约束生效」都要配一条「合法用户仍可用」，含纯 MCP 用户不依赖 WebUI Cookie。

## 不得关闭的情形

- A3 只有推测，没有诊断证据。
- A6 只在降规模或 1 CPU 单链路下通过。
- 混压期间用重启或手工操作换取「恢复」。
- 压测用桩服务、关闭业务路由，或只验 HTTP 状态码而不核对 SQL 值。
- 因 `readyz` 为 200 而判定「健康」。
- 修复让纯 MCP 合法用户必须依赖 WebUI Cookie 才能恢复。
- 以进度百分比代替本表逐条状态。
