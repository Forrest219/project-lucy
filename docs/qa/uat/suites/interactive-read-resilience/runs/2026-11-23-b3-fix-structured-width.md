## B3 扣留复验

用之前的小夹具，四页各跑 3 次真实前台。每轮设置独立 `sources` 冷槽，同一进程内扣留真实构建 12 秒。两个受影响页面的 6 次首读均在 **4,006–4,013 ms** 收到 `503 DISPLAY_SNAPSHOT_BUSY`，`Retry-After: 1`，逐次内部原因为 `build_wait_timeout`。浏览器自动重试仍收到明确的 503；两次请求共用一个底层构建。释放后 6 次复读均取得 200，并于 **652–680 ms** 内看到正确内容。浏览器未在首读或自动重试中止请求。

角色权限、Agent 名册的独立对照 6 次均显示正确内容，前台就绪 **159–334 ms**。直连与反代的 `livez`／`readyz` 共 **672/672** 个 200，最大 **103 ms**。正常鉴权读 36/36 成交。12 条新纯 MCP 完整旅程查得与独立 SQL 一致的 1,000 条订单。主进程同一时窗内保持服务能力。

单测覆盖发起请求和附着请求同时到期后仍保留一个在途构建、迟到成功可命中，以及代次变化后丢弃迟到结果。快照、失效隔离、角色和两组名册共 187 项通过，TypeScript 类型检查通过。

## CPU 采样

另做一轮 1 CPU 复跑，Node 主进程 CPU profile 的有效采样时间为 19.30 秒。YAML 解析栈累计 10.52 秒（约 55%），GC 自耗时 3.83 秒（约 20%）。最近的 Lucy 解析调用点包括 `semantic-layer.ts` 的 `parseYaml` 4.99 秒、ACL 的 `buildSourceMapFromDisk` 2.64 秒、独立目录描述装载 1.28 秒及查询歧义目录 1.22 秒。这些是整个 profile 内的累计时间，采样窗口包括前台冷读、握手、独立目录和两条真实查询。1 CPU 采样复跑的健康窗口事件循环最大为 1.59 秒。[语义资产解析](../../../../../../webui/server/semantic-layer.ts#L257) · [ACL Source Map](../../../../../../webui/server/proxy/acl.ts#L372)

后续可先用单变量对照验证同一文件代次的解析结果能否跨入口复用，且每次继续独立执行授权。在证实单次冷解析仍超预算时，再评估主线程外执行。CPU 归因能解释结构宽度造成的竞争，现场握手长尾还需对应证据。
