## 初次有效名册对照

三个热态样本无 503，导航到名册就绪为 480–640 ms。用正式 PATCH 提交合成 Agent 备注时，20:11:19.268 收到一个名册摘要 `DISPLAY_SNAPSHOT_BUSY` 503，`Server-Timing total` 为 1,515.5 ms，`builds=0`。写入最终收到 `policyRuntimeAck=true`。20:11:20.931 同次页面重试返回 200，`cache=miss`、`builds=1`，整页就绪 3.92 s，无重启。随后另一次打开也返回 200。完整名册对照返回 1,159,159 字节和 1,347 个实际能力条目。

该轮合成身份的 `tools/list` 因 `role_resolution_failed:demo_readonly` 返回 403，握手返回的是 9,359 字节的静态指引。其 200 次顺序和 20 次并发的 HTTP 200 保留为失败定位证据，宽目录握手耗时以有效身份的样本为准。
