## SC-08 B3 局部构建变慢

本机测程为 `sources` 各轮设置独立缓存键，在真实构建回调开头异步扣留 12 秒。保留生产代码的核验、并发构建、等待和响应逻辑，以相同进程记录构建开始及释放。B3 测量窗口内的 WebUI 请求日志没有配置写入。前台导航到内容／错误可见与 API 时间分别取证。

| 前台页面 | 样本 | 首尝及独立控制 |
|---|---:|---|
| 语义资产 `/catalog` | 3 | `sources` 全部在 **10,006–10,009 ms** 被浏览器中止。修正测程选择器后，两次在导航后 **10,643–10,854 ms** 看到超时。 |
| 概览 `/overview` | 3 | `sources` 全部在 **10,001–10,007 ms** 被浏览器中止。修正后的两次在 **10,462–10,465 ms** 看到超时。 |
| 角色权限 `/admin/roles` | 1 | 同一 `sources` 构建扣留期间，角色读取首响应 `200`，API 响应头 **11 ms**，页面就绪 **145 ms**。 |
| Agent 名册 `/admin/agents` | 1 | 同一 `sources` 构建扣留期间，名册读取首响应 `200`，API 响应头 **33 ms**，页面就绪 **419 ms**。 |

- 两个受影响页面的 6 次首尝全部在构建释放前约 **2.01–2.06 秒**中止，均未收到可重试 503。修正测程后的 4 次复读在释放后 **484–530 ms** 发出，正确内容在释放后 **572–749 ms** 可见。首次测程的两次恢复发起晚于 1 秒，仅保留其首尝失败与恢复诊断。
- 直连／反代 `livez` 与 `readyz` 共 **448/448** 个 `200`，端到端最大 **64.3 ms**。24 个独立鉴权读全部 `200`，最大 **233.9 ms**。修正测程后的 4 条同窗 `initialize → tools/list → lucy_catalog → lucy_query` 旅程全部取得正确订单数 **1,000**。首次测程的查询汇总解析器未适配位置行，首轮查询结果不计入通过分母。
- 该工况证实慢构建等待可以让浏览器先中止。同窗探针与独立读取均成交，支持将此复现定位到 `sources` 构建响应等待。下一候选可优先为请求等待设置早于浏览器中止的上限，同时保留底层构建去重、容量记账及完成后的授权与代次核验。[快照读实现](../../../../../../webui/server/display-snapshot.ts#L817)

## MCP 大 Manifest 与异步扣留对照

同一合成 Manifest 保持解析结果一致，以 YAML 注释将实际容器文件从 **7,466** 扩为 **2,347,590 字节**。每个字节档重启 Lucy 并等就绪后发起第一条完整纯 MCP 旅程，再采 10 次独立新会话握手。重启首个请求包含启动就绪可能已经完成的预热，测试为单连接、单 Manifest 的文件大小对照。

| 条件 | 首个 `initialize` | 后续 `initialize` 中位／最大 | 首个目录／查询 | 结果 |
|---|---:|---:|---:|---|
| 7,466 字节 | 30.8 ms，完整指引 | 11.7／29.2 ms | 18.3／835.5 ms | 查询 1,000 |
| 2,347,590 字节 | 27.6 ms，完整指引 | 11.6／18.6 ms | 38.9／712.1 ms | 查询 1,000 |
| 大文件加 3 秒异步扣留 | 1,019.6 ms，基础指引 | 单次 1,011.1 ms，基础指引 | 37.3／636.3 ms | 两次审计均为 `deadline`，首条完整旅程查询 1,000。两条底层任务约 3 秒后实际结束。 |

两个字节档首个握手的 `catalog_resolve`、`skills_load` 均约 **3 ms**，未复现现场长尾。全局多连接、真实 YAML 对象宽度、并发及主线程同步阻塞仍需各自验证。两种指引均实测包含 P1-77 新规则，本镜像不能用作 P1-75-only 候选 A。
