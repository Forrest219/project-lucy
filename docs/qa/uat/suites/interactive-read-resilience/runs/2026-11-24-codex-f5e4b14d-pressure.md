## 确定性验证与受控故障

- T0 判定器校准 14/14。五个仓库测试文件 92/92 通过，另有两个测试专用控制通过。用钩子实际占满 20 个目录位置，取消一个客户端时继续保持占用。底层工作终止后恰好腾出一个位置，补回一个后再次拒绝超额，全部结束计数归零。假时钟分别核对两种新鲜期限、宽限截止及回拨，回拨产生负年龄时当前实现仍判新鲜。
- 元数据和全量摘要分别扣留，宽限期均返回 200、`degraded;desc=grace` 和同代次内容，同窗无登录请求均返回 401。超界后分别为 `metadata_overdue` 和 `digest_overdue`，两次均为 503 且 `Retry-After: 1`。解除后正确响应分别约 96 ms 和 260 ms。
- 在单独的测试专用 Docker 实例中扣留一次共享构建，五个不同发起时刻的读取在 4.006–4.058 秒收到 `build_wait_timeout` 和 `Retry-After: 1`。独立角色读为 200，解除后约 1.72 秒读到新代次。该组为真实接口的受控 API 取证。
- 1 CPU 启动对照在 `health` 已通、`readyz` 未通时发起 30 条鉴权读取，22 条返回 503。就绪后 90 条并发读和 10 条顺序完整名册读全部为 200。
- Skill 外部撤权 12 条实际 MCP 回执通过。旧、新会话均按新 Skill 权限处理，保留的业务查询均得到 1,000。
- 外部禁用一个合成 Agent 后，宽限中的名册先返回 503。核验放行后名册已明确显示禁用。观察约 40 秒时，旧 MCP 会话仍查得 1,000，新会话仍能初始化。未观察到对应的 MCP 策略发布确认，这组记录展示和执行的实际生效差异。末尾的独立合法 Agent 对照仍查得 1,000。夹具原文件已恢复，管理面多角色与正式授权发布矩阵仍缺证。

## MCP 握手、独立目录与断连

- 同候选正式角色暖态顺序 200/200，P50 17.37 ms，P99 34.43 ms。三轮反代和三轮直连的 20 路批次全部成交且无基础指引，反代 P50 148.69–178.27 ms、P99 214.50–268.33 ms，直连 P50 123.14–167.52 ms、P99 231.91–242.34 ms。实际指引包含 P1-77 业务上下文，原隔离判定器未通过。
- 独立目录阶梯合计 1,772 个请求，1,309 成功、286 收到繁忙、177 由客户端取消。119 条取消被审计关联为 `client_disconnected`。取消后的 400 条再接纳均成功，T1 的 29 条查询核对均成功。其余客户端取消有已写出、达到容量或缺终态等不同证据状态，按请求保留。服务端容量检查分段为 0 ms，客户端忙碌回执最大约 2.00 秒。
- 补充独立身份压力使用 50 个合成 Agent，50/50 握手；其中 19 个实际发现了合法查询工具，3/19 在 10 秒内完成并核对正确值。角色预选与实际工具权限存在差异，记录为夹具和受测结果，正式 G2 的三角色、八连接、写入同窗和服务端在途分母均需另行满足。

## 并行 stat 单变量诊断

相同 1,416 个 YAML 文件和两个预选连接，用同候选分别执行串行与分批 stat。运行采用离线临时容器，分批版本暖态一个请求的指纹 P95 由 170.0 ms 降至 20.1 ms。20 并发的指纹 P95 由 676.0 ms 降至 578.5 ms，同进程小文件探针 P99 从 54.0 ms 升至 125.9 ms。20 个同时失效调用在两组都发生了 20 次重建。枚举与 stat 之间删除合成文件的控制触发一次 `uncacheable`，回退读仍返回剩余记录。此组说明 I/O 竞争及重复重建风险，整机退化按真实混压另判。

## T2 自然混压

北京时间 10:16:05 起按 1 Hz 调度共 900 次每入口／每 API 探针，10:31:04 完成最后一次发起，10:31:33 收齐终态。15 轮每分钟 50 路独立目录突发，间插 20 路新握手及主动断连。同一 `lucy_admin` 身份的工具发现按 1 Hz 发起，实际查询按开放到达每 5 秒一条。前台 Chrome 和独立诊断共享宿主资源，同一候选的暖态和 T1 在混压前单独采集。

| 观察项 | 结果 |
|---|---|
| 合法问数 | 预检查询正确。正式混压 180 条均触发客户端 30 秒截止。独立客户端交叉验证中，握手、工具发现和目录返回后，真实查询同样到 30 秒截止。 |
| 握手与工具发现 | 482/482 握手成交，其中 426 次基础指引。工具发现 900/900 成交。 |
| 独立目录 | 750 条中，470 条成功、130 条返回繁忙、150 条由客户端取消。 |
| `livez` | 两入口各 900/900 为 200。直连／反代 P99 约 1.199／1.205 秒，最大约 2.368／2.369 秒，超过 P99 400 ms、最大 1 秒的预算。 |
| `readyz` | 两入口各 900/900 为 200。直连／反代 P99 约 1.197／1.205 秒，在 1.5 秒 P99 预算内。 |
| 普通鉴权读取 | 两入口各 898/900 正确响应、各 2 次客户端超时。直连／反代 P99 约 3.522／3.700 秒，超过每次 3 秒预算。 |
| 展示读取 | 在概览、语义资产、Agent 名册和角色权限的前台网络采样中记录真实 `DISPLAY_SNAPSHOT_BUSY`。原始回执保留首个 503 和自动重试的独立状态。快照日志记录全量摘要年龄超宽限。 |

停压后在同一个运行实例中继续观察约 134 秒，三条展示接口各 30 次读，共 80 条 503 和 10 条客户端超时，`readyz` 30/30 为 200。独立客户端的两条业务查询均在握手、发现和目录通过后到达 30 秒截止。同实例恢复未达门槛。

随后单独重启本次测试容器。重启后的三条展示读首轮都为 200，耗时 113–243 ms，两条完整问数旅程分别用时 5.27 秒和 6.13 秒，返回独立 SQL 核对值 1,000 和 3。重启前后容器起始时刻和两组原始回执均留存。

## 首页和身份页响应体积

500 Agent 同夹具独立读取时，摘要为 270,943 字节，显式完整名册为 3,912,167 字节，约为完整响应的 6.9%。真实前台初轮 34 次导航未观察到隐式完整名册请求。初轮概览测程错误地把一个未发起的可选请求计入等待，网络请求及首个失败保留。校准后复跑概览，前台焦点有效 10/10，`/api/project` 首响应 10/10 为 200，语义资产与名册摘要首响应 10/10 为 503，无有效主内容就绪。其余页面保留首轮网络证据，接入向导最后一步及各身份页面的完整冷／暖分母未封存。
