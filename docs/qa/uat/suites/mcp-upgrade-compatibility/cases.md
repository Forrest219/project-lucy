| ID | 标题 | 期望摘要 |
|---|---|---|
| UAT-COMPAT-R0 | 身份与全真环境门禁 | PRE／候选／POST 身份、Public MCP、真实 Agent／模型、**数据快照 ID**、Role／Token 指纹与题库摘要明确；不匹配即 BLOCKED |
| UAT-COMPAT-01 | 独立简单单表问题 | 真实 Agent 自然语言提问；typed gold 正确，至少一条本问真实 `lucy_query` |
| UAT-COMPAT-02 | 时间、过滤、分组与合法空结果 | 各独立问题结果正确；合法空结果不是错误，也不得冒充非空基线 |
| UAT-COMPAT-03 | 同会话时间窗连续追问 | 「那 12 月呢？」等沿用前文；禁止重开新会话或改写成独立完整问题 |
| UAT-COMPAT-04 | 同会话分组与比较追问 | 「再按区域拆分」「和上月相比呢？」上下文与计算正确，逐轮计时 |
| UAT-COMPAT-05 | 单表、多表 join 与单表扩展多表 | 已声明 join 成交；同会话从单表扩展关联表仍成交且口径正确 |
| UAT-COMPAT-06 | 单库到多库 | 连接 A／B 分别查询并对比；非法跨连接混查拒绝且提示按连接拆分，无越权 |

| UAT-COMPAT-08 | 表／行／字段分权限 | 表 A／B、华东／西南、字段可见性符合 Role；deny→allow 或串权 FAIL；同身份合法对照成交 |
| UAT-COMPAT-09 | 会员收入事故永久看守 | Demo＝ESC-11 同形；客户＝私有基线重放；首次不得 `source_ambiguity_gate` |
| UAT-COMPAT-10 | 冷启动首轮与稳态 | Ready 后首轮和稳态均完成真实问答；首轮单列，不被稳态样本掩盖 |
| UAT-COMPAT-11 | 绝对耗时与完整计时 | MCP 绝对预算硬拦；Agent 墙钟目标 120s／轮，越线须 D16a 审计；计时字段完整 |
| UAT-COMPAT-12 | 相对退化与回滚恢复 | PRE／POST 可比；相对双门达标；`ROLLBACK_VERIFY`；发布证据绑定与反篡改负例通过 |

## 通用判定规则

1. 真实 Agent 最终答案必须与本问 typed gold 和真实服务端查询对账；只有文字答案或无关查询不算 PASS。
2. 基线成功的请求在 POST 出现新增 deny、error、空信封、**快照未变**却非空变空或预期指标缺失均 FAIL。
3. 基线应拒绝的请求在 POST 变为允许、返回越权数据或泄露受限身份均 FAIL。
4. 任一必需轮次、客户端、尝试或样本缺失即分母不完整；禁止只保留最快／成功样本。
5. 功能／权限不接受 PASS WITH GAP；Agent 墙钟仅允许 Spec D16a 有限例外。
6. 通用车道可用 D21 合成夹具（用后还原）；客户车道禁止伪造 PRE。出包＝`certifyCandidate`；升级＝`certifyInstanceUpgrade`——二者不得互相冒充。

## UAT-COMPAT-R0 — 身份与环境

### 步骤

1. 记录候选／PRE／POST 的完整 `gitSha`、镜像 digest、Public MCP URL、Agent／模型版本、Token 指纹、题库 SHA256、**数据快照 ID**。
2. 核对与发布合同声明一致；通用车道确认合成夹具可还原；客户车道确认私有基线路径 0700／0600。

### 期望

身份齐全且匹配；缺任一项 → **BLOCKED**（不得开跑冒充 PASS）。

---

## UAT-COMPAT-01 — 独立简单单表

### 步骤

1. 真实 Agent 用自然语言问一道单表简单指标题（通用：demo `superstore_orders`；客户：私有基线题）。
2. 保存最终答案、本问真实 `lucy_query` 请求 ID、typed gold 对账。

### 期望

答案与 gold 一致；至少一条真实成交查询；禁止无查询文字凑绿。

---

## UAT-COMPAT-02 — 时间／过滤／分组／合法空

### 步骤

1. 各发独立问题：带时间窗、带过滤、带分组、故意合法空结果各至少一题。
2. 对账 typed gold 或客户合同形状。

### 期望

非空题不得变空（快照未变时）；合法空不得当错误，也不得冒充非空基线。

---

## UAT-COMPAT-03／04 — 连续追问

### 步骤

1. 在一个真实 Agent 会话中问首轮指标题。  
   - **客户层**：可用「查询 2025 年 11 月会员收入」等私有基线原文。  
   - **通用 demo**：无客户表时改用题库冻结的同形词（如超市订单销售额），**不得**因无「会员收入」表删题。
2. 同会话追问「那 12 月呢？」。
3. 同会话追问「再按区域拆分」（客户无区域维则用私有基线等价维）。
4. 同会话追问「和上月相比呢？」。
5. 对每轮保存最终答案、真实请求 ID、用户墙钟与 MCP／服务端耗时。

### 期望

- 各轮分别保留时间窗、分组与比较语义；不得每轮重新开始无关旅程。
- 所有合法轮次成交；出现 `source_ambiguity_gate`、上下文丢失、无真实查询或超时均 FAIL（Agent 墙钟超时按 D16a）。

---

## UAT-COMPAT-05 — 单表到多表

### 步骤

1. 首轮单表成交。
2. 同会话扩展到语义层已声明 join 的关联表（demo：orders→returns／people）。
3. 对照：未声明 join 的多来源不得发明跨表成交冒充 PASS。

### 期望

已声明 join 成交且口径正确；非法多表按产品合同拒绝或上游真实错误，不得越权。

---

## UAT-COMPAT-06 — 多库

### 步骤

1. 在同一授权身份下分别询问连接 A 与连接 B 的既有指标。
2. 要求基于两次已授权结果做对比。
3. 用无 B 权限身份重复，确认不泄露 B。
4. 发起产品不支持的跨连接混查，观察拒绝与下一步。

### 期望

- 合法分别查询与对比成交，不发明跨连接 join。
- 无权限身份不得看到 B 的数据或受限身份；混查提示按连接拆分。

---

## UAT-COMPAT-07 — 无工具／无 Source

### 步骤

1. 使用无 `lucy_query`（或等价）权限身份提问 → 须快速拒绝、无上游越权。
2. 使用无 Source 可见身份提问 → 明确拒绝、无泄露。
3. 同题用合法对照身份 → 须成交。

### 期望

拒绝明确；deny→allow FAIL；合法对照 PASS。

---

## UAT-COMPAT-08 — 表／行／字段分权限

### 步骤

1. 表 A 可见／表 B 不可见：问 B → 拒绝；问 A → 成交。
2. 行权限（通用可用合成华东／西南夹具；客户用既有 Role）：越权行不可见。
3. 字段暴露差分：受限字段不得出现在成功结果。
4. 每项保留合法对照成交。

### 期望

分权限生效；串权／泄露／deny→allow 均 FAIL。

---

## UAT-COMPAT-09 — 事故负控与修复后

1. **负控（SC-14）**：优先用固定坏 digest／冻结失败证据包回放判定器；可选在未修旧实例全真复验。预期能抓住 `source_ambiguity_gate` 事故。
2. 在修复候选上以泛化业务词 begin，再首次查询已明确唯一来源的指标。
3. 客户层用既有 WorkBuddy／MCP 配置与 Token 重放实际会员收入基线。
4. 记录首次结果，不允许先 deny 再重试凑绿。

### Demo 层与客户层分判

| 层 | 环境 | 映射 | 放行含义 |
|---|---|---|---|
| Demo 同形 | 本机 demo／通用候选＋MCP | 必跑／复用 [`UAT-SAG-ESC-11`](../source-ambiguity-mcp-escape/cases.md) | 证明事故类路径在候选镜像上已修；**≠** 客户实例放行 |
| 客户基线 | 客户既有 Public MCP＋Token＋私有参数 | 本条步骤 3；私有基线 0700／0600 仓外 | 无基线 → **BLOCKED**，不得客户升级／出包声称「COMPAT-09 客户 PASS」 |

---

## UAT-COMPAT-10 — 冷启动首轮

### 步骤

1. Ready 后立即发首轮真实问答（MCP 对照＋Agent 各至少一题）。
2. 稳态后再跑同题。
3. 首轮与稳态分列证据。

### 期望

首轮不得被稳态样本替代；MCP 首轮受 D11 MCP 绝对预算；Agent 首轮按 D16a。

---

## UAT-COMPAT-11／12 — 耗时与回滚

每轮记录 `turnWallClockMs`、`mcpClientRttMs[]`、`serverDurationMs[]`、重试与 `unattributedMs`。trace span 缺失时不编造阶段耗时；600 秒技术终止线不是体验合格线。

- MCP 绝对／相对：Spec D11／D12 硬拦。
- Agent 墙钟：目标 ≤120s／轮；越线须 `agentWallClockException` 审计字段（D16a），且 MCP 对照仍 PASS。
- COMPAT-12：PRE／POST 相对双门；回滚后 `ROLLBACK_VERIFY` 同基线恢复；发布证据反篡改负例通过。
