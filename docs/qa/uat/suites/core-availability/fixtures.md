# Core Availability Fixtures

本文为设计下限，不是客户实测。所有档位执行前冻结；不足则BLOCKED，不以缩小夹具、预热、改截止或修改历史时间戳追样本。当前没有构造或执行授权。

## 通用身份与环境

- 默认本机隔离Docker单实例单副本；2 vCPU、2GiB，独立卷，明确宿主架构/镜像架构。功能验证允许本机原生架构；amd64客户出包不在本轮。
- 隔离测试管理员及两个不同普通MCP身份；Token用私有凭据文件，不写inbox/测试台；纯MCP不带WebUI Cookie，不依赖宿主attestation。各功能子集固定合法轻量数据查询、独立预期结果与身份范围，握手或tools/list成功不能代替数据查询成交。
- 同一候选digest、gitSha、dirty与fixture指纹；另保留改前镜像。同一产品版本名或SHA不足以代替镜像身份。
- 权限拒绝由真实测试身份的配置产生；业务数据为自产合成数据，不能用客户生产库做故障注入。

## F61诊断I/O

- 使用隔离Linux卷的真实限速/延迟条件及足够大的合成配置/诊断文件，证明诊断采集实际耗时≥5秒或实际I/O失败；主服务已完成安全预热及两端口监听。
- 若单靠现有blkio达不到条件，保持BLOCKED，提出额外测试环境授权；不能在产品代码中sleep或mock collector后称全真。
- 120秒各1Hz livez/readyz，容器内单调时钟计时；指标含全部样本和请求内I/O独立计数。周期10秒、采集截止5秒；首次采集失败立即stale，持续失败30秒后仍stale；p99采用nearest-rank，不删慢样本。
- 时钟回拨、代次竞态、不可取消底层工作的单元反例与真实I/O进程证据分开标层级。

## F62容量与原模块金样本

- 三类别总running=2、各类1、waiting=16、同身份同类waiting=4、队列截止5000ms（容差100ms）；这是待确权提案，不是现场现值。
- 至少80个实际HTTP/后台提交，两个身份，三类均有真实工作。后台重建票据固定≤1，不把67用户全部展开为队列闭包。
- 三条任务输入先通过各自可用性基线：重建用原67用户夹具；导出选现有可用诊断/普通范围，不用P1-57 D7延期正式完整导出成功作前提；批量发现用既有 [large-schema fixtures](../large-schema-ingestion/fixtures.md) 的真实测试数据库和合法字段路径。
- 记录原模块deadline，5秒排队必须计入；真实下游迟退/连接断开以及“事务安全点已到但子进程未退”用于验证permit，不能用调度器自报running作为唯一oracle。许可释放证据必须覆盖子进程、DB连接和输出句柄实际关闭。
- 普通已鉴权只读请求≥1Hz、120秒，同窗每次正确返回；不带WebUI Cookie的纯MCP在饱和窗完成 `initialize`→`tools/list`→合法轻量数据查询并核对独立预期。F62只断言接线与可用，不替代系统并发性能。预期容量拒绝仍保留数量/耗时，不能计入成功吞吐。

## F63进程/信号

- 真实entrypoint/supervisor/KTX与Lucy；记录实际PID/父子关系和信号接收确认。内部drain确认通道尚待设计确权，不假定已有命令。
- 真实测试DB的可控延迟查询约10秒与>20秒两类，另有空闲SSE/业务RPC；不在应用发送响应前sleep替代仍依赖KTX的操作。
- 默认排空20秒（含取消通知与剩余状态记录）、supervisor停止10秒、孤儿清理≤5秒、其余收尾≤5秒、总退出40秒；标准Docker demo及测试容器grace≥45秒，并保存Compose渲染证据。短grace和自定义stop超时冲突作为负控，不能改预算悄悄通过。
- ≥100轮准入/信号竞态；三轮有限查询排空。每轮用事务/领域回执证明执行次数。SIGKILL/OOM是恢复边界，不计“排空成功”。

## R-CAV补充组合档

- 复用 [cold-start fixtures](../cold-start-slow-disk/fixtures.md) 与 [rebuild-probe-budget fixtures](../rebuild-probe-budget/fixtures.md)：当前窗口≥20万真实合成调用、67用户完整唯一有效关联；慢盘读写30MB/s、读300/写100 IOPS、2核；冷缓存操作只在获授权隔离台执行。
- 不修改原模块夹具/门槛；R-CAV普通HTTP固定每秒1次，MCP每秒1个顺序合法轻查询，真实测试源结果可独立核对。若原P1-13或被消费模块要求更大负载，取更严格者。
- 重任务提交基线每类每10秒1次；2×为每类每5秒1次，5×为每类每2秒1次，各120秒。记录计划与实际到达量，不因积压退成闭环低速；业务响应较慢时保留未完成/超时，不虚构达到速率。
- 本机真实反代记录upstream/status/耗时，真实测试源停服仅影响指定源；全局配置损坏或授权状态不确定不能套“单源降级”放行。
- 原P1-13／52／53的场景/分母与真实Agent要求继续有效；R-CAV不替代它们。客户倍率、实际PVC、网关传播尚未测，不宣称现场问题已复现。
