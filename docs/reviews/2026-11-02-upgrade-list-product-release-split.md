## L25-02／03 收了什么

已收口的读取合同：

- `webui/server/__tests__/reconciliation.test.ts`：同名表不合并，未知桶不猜表，尝试数缺失不填 0，只有真实预算凭据显示用尽，候选与握手分列，八桶闭合，Token 差异可复算，分母为 0 不显示 0% 或 100%。
- `webui/server/__tests__/reconciliation-context.test.ts`：水位取账本上界，窗口只接受 24／168／720，同一次读取共用上下文。
- `webui/server/__tests__/reconciliation-csv.test.ts`：五类文件、空值与 0 分开、完整表身份、不导出凭据。
- `webui/server/__tests__/audit-reconciliation-routes.test.ts`：三个只读端点；meta-audit 或安全库失败拒绝读取；actor 不可解析返回 401；六项覆盖检查缺证据保持 `unknown`；无序号行返回 409。
- `webui/src/__tests__/audit-reconciliation-page.test.tsx`：用量页规模为 null 显示不可观测，不显示 0；比率给出 N／D；as-of 不可证明时显式诊断；活跃数超过配置数不直接说成数据异常。
- `webui/server/__tests__/audit-v025-as-of-proof.test.ts`：正式导出在 as-of 不可证明时失败关闭。该文件的其余断言属于 L25-09，不在这里重复收口。

仍未收口的产品句子：

- 对账问询详情页不把长表清单收成「等 N 个」。读模型函数有断言，页面组件没有。
- 表排行视觉截断后仍可展开或复制完整连接／Schema／表。没有组件断言。

归 `ARV25`，不记通过：浏览器详情、真实事件全集、同一次读取里 API／页面／CSV 互相对上、客户 linux/amd64 单副本。
