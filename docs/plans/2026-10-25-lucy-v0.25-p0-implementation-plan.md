## 2. 关键依赖与实施顺序

四个 P0 不是并列的，存在三处硬依赖：

```
        ┌─────────────────────────────────────────────┐
        │  W1a 共享基座（新建，Wave 1 前置）            │
        │  · 单实例发布协调器（P0-3 D4 / P0-2 D6 共用） │
        │  · durable config 审计 intent/terminal 拆分   │
        │  · 候选摘要统一口径（policyDigest/planDigest） │
        └───────────────┬─────────────────────────────┘
                        │
        ┌───────────────┴───────────────┐
        │                               │
┌───────▼────────┐            ┌─────────▼──────────┐
│ W1b P0-1 审计   │            │ W1c P0-2 行权限     │
│ S01–S08         │            │ R5 → R2 → R4       │
│ （含 S05 主状态）│            │                    │
└───────┬────────┘            └─────────┬──────────┘
        │                               │
        │  ┌────────────────────────────┘
        │  │
┌───────▼────────┐            ┌─────────▼──────────┐
│ W1d P0-3 批量   │            │ W2 P0-4 对账展示     │
│ 身份→包→校验→   │            │ （强依赖 P0-1 S05） │
│ 发布→恢复       │            └────────────────────┘
└────────────────┘
```

- **W1c 必须先于 W1d 落地协调器接入**：P0-3 D4 与 P0-2 D6 指向同一个协调器，谁先定义 API 谁定契约。本计划由 W1a 一次性定义两侧接口。
- **P0-4 必须最后做**：Spec §2.1 要求「主状态使用 L25-09 S01 的八桶与 `derivationVersion=v2p5-1`」，而该派生函数在当前代码中**完全不存在**（`budget_stopped` / `indeterminate` / `v2p5-1` 全仓 0 命中）。P0-4 复用 P0-1 的产物，不自建第二套口径。
