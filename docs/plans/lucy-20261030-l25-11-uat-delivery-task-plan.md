## 目标

在不放宽冻结合同的前提下，把 L25-11 推进到本环境可核对的 UAT 证据。本环境指当前已载入工作区代码的 Docker，加上桌面浏览器。客户交付保持阻断。

- 产品语义以 2026-10-27 独立审阅为准，不撤销。复审重判当前调用链，不用该报告里的旧行号当现行缺陷清单。
- [发布窗口 Task](2026-10-30-l25-11-publish-window-task.md) 的三处收口仍然有效。该文件里「不回填 V01–V22」「不改升级建议书版本号」由本 Task 的波次 D、C 接替，且只在对应门禁满足后执行。
- `3b7e8d32` 已把发布锁留到摘要核验、终结审计、`published` 和日志完成之后。工作区另有四笔未提交边角：放锁失败重试、索引成功后的异常改为 `recovery_required`、目录重载成功后才完成日志、窗口内再查一次未决恢复。这四笔还不是复审基线。
- 工作区同时夹着访问关系图、问询预算、发版体验等无关改动。波次 A 只带走 L25-11 的文件。
- 当前 Docker 已是工作区代码。波次 A 再改运行代码之后，波次 D 开始前做平滑升级，保留已有 volume。
- 批量校验仍只返回 `operationId`、`taskId`、`scopeId` 和 `status: queued`。G30 继续开着。本 Task 不关闭它，也不因此停掉 L25-11 自己的 V 矩阵。W-B 继续不可交付开发。

## 验收

- 波次 A 的容量拒绝对应 V13(d) 的「未满 24 小时不淘汰」这一子断言。镜像失败对应 V14(d)、V15(b)、V19(c) 里「镜像异常不得记 restored／published」这一子断言。其余子断言不因这两则测试而通过。
- 波次 D 的桌面证据只用于 V02、V20。不做移动窄屏。页面截图不能代替前后 hash、拒绝码和 journal。
- 波次 D 不跑客户 linux/amd64，不用本机 Compose 填写 V22。
- real-e2e 上已有的 V 标签宽于断言时，不把标签当成整项证据（M01）。新增证据的标签只写实际断言。

## 完成定义

本 Task 完成，须同时满足：

1. 波次 A 的差异可核对，且容量拒绝、镜像失败关闭有测试输出。
2. 波次 B 有独立审阅结论。结论为退回时，本 Task 停在退回，不称为 UAT 已交付。
3. 结论接受后，波次 C 的登记册已改，G30 仍开，W-B 仍关。
4. 波次 D、E 的证据映射已落盘。已通过的 V 项是全部子断言都有直接证据的项。V03(d) 与 V22 仍是 `blocked_delivery`。
5. 客户交付保持 `blocked_delivery`。本环境证据不解锁 Wave 0b。
