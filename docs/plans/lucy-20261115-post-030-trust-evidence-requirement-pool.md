## REQ-TE-001｜可核对块覆盖认证路线／报告模板

| 字段 | 内容 |
|---|---|
| 缺口 | 成功路径 `lucy_certified_route`／`lucy_report_template` 不强制带与 `lucy_query` 同形的 `answer_verifiability`；越是「已治理」路径越不可核 |
| 期望方向 | 三条路径成功答复同形可核对块；`cutoff` 在物理真源未接前仍诚实 `not_checked`；默认只出引用／哈希，SQL 原文需显式授权 |
| 依赖 | 复用 P0-4 块契约；不重造 provenance |
| 非目标 | 宿主强制渲染；认证徽章产品面（见 004） |
| 状态 | 入池；未立项；**不进 0.30 总账跟进** |

## REQ-TE-002｜统一可信证据载荷槽位

| 字段 | 内容 |
|---|---|
| 缺口 | 结果载荷尚无并列的认证态／质量预警槽；聊天、报告、其他宿主无法共读同一风险信息 |
| 期望方向 | 统一字段：新鲜度、`certification`（可缺省／not_certified）、`quality_warnings[]`（可空）；对象带 `layer`；不做综合分 |
| 依赖 | 可挂在可核对块扩展或 `_meta.lucy` 并列；契约先行，允许槽位为空 |
| 非目标 | 自建 DQ 检测平台；把槽位填满当作本条出口 |
| 状态 | 入池；未立项 |

## REQ-TE-003｜监控型管道／刷新失败风险揭示

| 字段 | 内容 |
|---|---|
| 缺口 | 管道／刷新失败无法作为与新鲜度并列的风险证据进入答复 |
| 期望方向 | 失败自动打标、随后成功自动清除；第一阶段只揭示不拦截；未检查 ≠ 正常 |
| 依赖 | 宜接在 **P0-B**（或等价物理真源）落地之后 |
| 非目标 | 人工对账类预警自动清除；因失败撤销认证 |
| 状态 | 入池；未立项 |

## REQ-TE-004｜认证对象分层与治理角色生命周期

| 字段 | 内容 |
|---|---|
| 缺口 | 有执行钩子无策展一等对象：谁认证、哪一层、哪一版、编辑是否失效均不可见 |
| 期望方向 | `layer`＝source｜metric_or_query｜report_conclusion；治理角色授予／更新说明／人工撤销；编辑定义 → 认证标识失效；复用「优先可见」非强制；权限不照搬「有写即可认证」 |
| 依赖 | 宜先有 001／002 载体；与「发布＝技术校验」语义划清 |
| 非目标 | 强制复用抢 P0-1 权威；认证自动过期（除非产品另定）；搜索加权／推荐列表照搬 |
| 状态 | 入池；未立项 |

## REQ-TE-005｜质量预警沿依赖向下游揭示

| 字段 | 内容 |
|---|---|
| 缺口 | 源／表级风险无法按实际依赖出现在指标与结论侧；认证与健康易被合成误解 |
| 期望方向 | 质量预警可继承／向下游揭示；认证本身不自动传染；监控型 vs 人工解除分轨；只揭示 |
| 依赖 | 002 槽位；最小血缘或依赖声明；Lucy 读证据不自建检测 |
| 非目标 | 质量拦截；综合可信分；敏感度与质量混类 |
| 状态 | 入池；未立项 |

## REQ-TE-006｜按用途「是否够用」规则证据

| 字段 | 内容 |
|---|---|
| 缺口 | 同数据用于探索 vs 结算的「够用」规则无配置化证据 |
| 期望方向 | 业务配置规则 → 结果里揭示「对本用途是否够用」；消费方决定是否采用 |
| 依赖 | 002／003／005；明确规则源 |
| 非目标 | 第一阶段按用途自动拦截 |
| 状态 | 入池；未立项 |

## REQ-TE-007｜结论与数据绑定

| 字段 | 内容 |
|---|---|
| 缺口 | 数据刷新／认证撤销／过期后，难以定位哪些已有结论需复核 |
| 期望方向 | 查询与报告引用所用数据版本与检查证据；恶化时可定位受影响结论并提示复核 |
| 依赖 | 证据格式可指向受影响对象（002）；依赖索引 |
| 非目标 | Live Report／看板编辑器／叙述短视频整包；本条不授权新 BI 面 |
| 状态 | 入池；未立项；**后置** |

## REQ-TE-008｜宿主强制渲染可信证据

| 字段 | 内容 |
|---|---|
| 缺口 | P0-4 只保证 MCP 载荷与 instructions；终端用户是否看见取决于宿主 |
| 期望方向 | 选定宿主（WebUI 或其他）强制渲染可核对／可信证据块 |
| 依赖 | 须**另行裁定**翻转或旁路 P0-4 O1＝A；建议 001／002 就绪后 |
| 非目标 | 用「工具结果里有字段」冒充「用户已看见」而不改宿主 |
| 状态 | 入池；未立项 |
