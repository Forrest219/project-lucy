## 问数约束（选表／口径）

- (P0-1 / REQ-030-027) 运维可为问题类型绑定唯一表与固定口径；命中绑定后若查询偏离，Proxy 直接拒绝且不往上游执行。
- (P0-2 / REQ-030-023) Catalog 对可见表带回业务描述等语义，便于按业务含义选表；**首期列表排序仍为字母序**（「业务相关排序」已降级，不进本版承诺）。
- (P0-A / REQ-030-012) Source 级可裁剪暴露给 Agent 的业务字段，缩小「权限内看得见但不该用」的面。
- (P0-3 / REQ-030-024) 多表命中时先澄清或失败关闭，禁止静默选错表成交。

## 答复呈现

- (P0-4 / REQ-030-022) 成功查询答复强制带上来源／口径／截止期等可核对信息（截止期物理真源未齐前可诚实标为未核对）。
- (P0-5 / REQ-030-018) 严格 0 行结果返回结构化下一步指导，减少空结果后瞎编或死循环。

## 问询预算与复盘

- (P1-12 / REQ-030-033) 默认问询预算窗口放宽为 60 次调用／300 秒（续查仍限 1 次），减少正常多步问数被过早掐断。
- (P1-14 / REQ-030-035) 审计可带上问询预算快照与 `calls.csv` 表尾字段，便于事后复盘「卡在预算还是卡在业务」。

## 概念治理（运维）

- (P1-11 / REQ-030-032) 概念注册表经 Lucy Ops 控制面维护：运维可用 Ops 工具完成扫描与人审写；本分支**唯一产品交付面＝Ops MCP**（不含 CLI／WebUI 概念页）。

## 连接与执行层

- (P1-15 / REQ-030-036；Spec 191) 创建或编辑连接后，有 supervisor 时写路径统一走执行层重载；成功面诚实回报配置是否已进入执行层，避免「保存成功但仍查旧连接」的假象。**不入核心分母**。

## Fixes
