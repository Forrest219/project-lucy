## 相对 v0.20.0 的用户可见增益

相对上一 tagged 客户版，本候选的核心增益是：治理台更能把「谁能看什么、问了什么、改错了怎么办」说清楚并可操作。本波（`origin/main..lucy-v0.25` tip，含合流门禁修复）用户可见主题包括：

- **访问关系图**：usage-first 几何与 scope 重投影；闲置授权文案与边悬停；固定已确认关联；小时明细表；与访问日志口径对齐。
- **访问日志调用链故事线**：一笔问询可按调用链读完轮次／调用／尝试。
- **系统手册**：补齐核心功能与非导航路由章节，并加工具面／章节锚定门禁。
- **客户默认系统正式 Role**：正式交付路径下默认系统 Role 功能合同收口。
- **lucy-ops Manifest 升级自愈**：存量升级后运维问数连接／资产可幂等补齐。
- **默认 asset_finance Skill**：四份财务规程收为默认业务 Skill。
- **row-policy 强度 B 证据**：共享 RDS 真实审判包与 harness 增量已入库；正式生产验收矩阵仍登记在 `0.30` 池。

更早已并入 `0.25.0` 产品线、且客户交付叙述通常需覆盖的能力（详见 `CHANGELOG.md` §`0.25.0` 与 `docs/releases/v0.25.0-customer-pre-delivery.md`）还包括：执行层重载、运维问数连接 `lucy-ops`、用量统计口径统一、行权限保存前预览、语义批量维护、发布批次整批恢复、审计失败关闭导出、OIDC／可选 SMTP／Skill 负责人等。上述能力「代码在仓」不等于对应正式验收矩阵已闭合。

- 本稿**不**虚构客户交付包、候选 registry digest、镜像摘要或包 SHA256。若同次出包产生上述身份，须写入 `docs/releases/v0.25.0.json` 后再对外引用。
