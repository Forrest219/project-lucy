Prompting

好问题会把 Lucy 从“回答机器”变成“分析伙伴”。

问题越接近业务决策，Lucy 越容易选择正确口径、维度和解释方式。

五条规则

  1. 说清时间范围：最近 30 天、2023-2026、当前快照。
  2. 说清指标：销售额、订单数、利润率、客户数。
  3. 说清维度：按区域、品类、客户细分、年份。
  4. 说清判断目标：找最高、最低、异常、改善优先级。
  5. 要求 Lucy 说明口径和限制。

从模糊到可验证

不要这样问改成这样问
销售怎么样？按年份和区域比较 2023-2026 年销售额、订单数和利润率，指出需要复盘的区域。
客户好不好？按客户细分比较总利润和利润率，并解释规模与效率的差异。
折扣是不是太高？用加权平均折扣率按品类排序，并说明是否影响利润率。
