Concepts

先理解概念，再相信答案。

Lucy 的回答质量来自一组约束：标准指标、数据路径、评测用例、人类测验和漂移治理。

关键术语

概念含义用户应该关心什么
Semantic Layer指标、维度、过滤条件和 join 路径的标准定义。优先要求 Lucy 使用标准口径。
Measure可计算指标，例如 order_count、profit_margin。同名业务指标必须口径一致。
Fallback语义层暂时表达不了的问题，使用受控 raw SQL 补充。必须说明原因、假设和可追溯来源。
Eval给 Agent 跑的机器评测题。验证模型会不会按正确方式做。
Quiz给人做的训练题。验证团队是否理解正确业务口径。
Data Drift底层数据变化导致结果值变化。不要把正常数据漂移误判为模型错误。

最容易误解的三件事

订单数不是行数

明细表一笔订单可能有多行，订单数通常需要 COUNT(DISTINCT order_id)。

平均折扣不是简单平均

折扣率通常要按销售额加权，避免小额订单扭曲结论。

利润率不是逐行平均

标准利润率应使用 SUM(profit) / SUM(sales)。
