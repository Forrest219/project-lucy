失败不是终点，失败要能分类处理。

当 Lucy 的回答不符合预期，先判断是问题不清、语义层未覆盖、数据漂移、逻辑回归，还是工具错误。

常见问题

现象可能原因处理方式
Lucy 给了数字但没有口径问题没有要求说明 measure 或来源。追问：请说明使用的 measure、过滤条件和数据来源。
Lucy 说 SL 不覆盖问题需要 cohort、窗口函数或尚未建模指标。要求给出 fallback 假设，并说明是否适合沉淀为新 measure。
同一问题今天答案变了可能是 data drift，也可能是逻辑回归。要求区分数据快照变化和 SQL/口径变化。
多轮追问口径变了上下文继承失败。明确要求沿用上一轮 measure、filter、dimension。

推荐追问

请重新回答，并列出：使用的 measure、SQL 口径、过滤条件、是否 fallback、当前数据快照。如果与上一轮不同，请说明差异原因。
