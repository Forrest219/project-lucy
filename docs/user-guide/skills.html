Governance

Skill 管理

Skill 是企业的分析肌肉记忆。把高频、高价值的分析逻辑以 YAML 格式固化，Agent 执行时直接调用，不需要每次重新推理步骤，也不会产生口径漂移。

什么是 Skill

Skill 存储在 Context Layer 的 skills/*.yaml 中。与 SQL 片段不同，一个 Skill 包含：分析目标（title）、所需输入（params）、推理步骤（steps）、输出格式，以及它依赖的 Measures 和维度。Agent 通过 Skill 名称调用，走 sl_read 或 sl_query 执行。

没有 Skill 时，每次问"各区域利润率对比"，Agent 重新推理该用哪个 Measure，可能因 prompt 差异产生不同口径。有 Skill 后，调用 skill:regional_profit_comparison，步骤和口径固定，答案可重现。

Skill YAML 结构

以下是一个完整 Skill 定义的示例：

name: regional_profit_comparison
title: 区域利润率对比
description: 按区域比较指定时间段的销售额和利润率，识别高销售低利润区域
version: "1.0"
params:
  - name: start_date
    type: date
    required: true
  - name: end_date
    type: date
    required: true
measures:
  - total_sales
  - profit_rate
dimensions:
  - region
filters:
  - is_deleted = 0
sort_by: profit_rate ASC
output_format: table_with_chart_hint

创建 Skill 的流程

1

新建 Skill

在 KTX WebUI 的「Skill」页新建，填写名称和描述。

2

定义参数与指标

定义 params（输入参数）和引用的 Measures，确保 Measures 已在语义层中定义。

3

添加 Eval 测试用例

在 Eval 里添加对应测试用例（给定 params 检查 SQL 结果）。

4

发布

Eval 通过后发布，Agent 即可通过 Skill 名称调用。
