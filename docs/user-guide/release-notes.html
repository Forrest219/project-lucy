更新日志

Lucy 及其 KTX 引擎的版本历史与重要变更。当前产品版本为 2.0.0，持续迭代中。

📌 完整的版本变更细节见仓库根目录的 CHANGELOG.md。本页只维护帮助文档站需要对齐的版本与能力状态。

当前版本

版本发布日期状态主要变更
2.0.0（当前） 2026-10-19 生产可用 产品版本线从 0.17.0 切到 2.0.0；Helm chart 版本仍是 0.2.4，内置 KTX 仍是 0.16.0，本次切换本身不改变权限、配置或 KTX 运行时。

已上线能力

功能状态说明
Bearer Token 鉴权 已上线 MCP 请求必须携带 Authorization: Bearer <token>。未携带、Token 不匹配、已撤销、已过期一律返回 401，没有匿名通道。
访问日志双 CSV 导出 已上线 访问日志提供「导出问询记录」与「导出调用流水」两个粒度，另有「导出审计证据包」；CSV 文件名带秒级时间戳和流水号。
质量评测 已上线 评测用例、运行历史、趋势监控、现场提问、安全评测候选五个入口。
访问治理 已上线 角色权限、Agent、Token 凭据、访问日志、MCP 调试台、配置审计六个入口。
数据库 driver 已上线 6 种：mysql / postgres / sqlserver / oracle / sqlite / athena。
