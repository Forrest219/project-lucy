Admin Guide

五步完成 Lucy 部署

从零到可用。完成以下五步后，你的团队就可以通过 Agent 发起数据问答请求了。

准备工作

开始部署前，请确认以下条件已满足：

条件说明
KTX 实例ktx CLI 已安装 (>=v0.4)，运行 ktx version 验证
数据库账号目标数据库的只读账号（SELECT 权限，无写权限）
Agent 接入Claude Code / Codex / Cursor 其中之一已配置好
Git 仓库用于存储语义层 YAML 与 Wiki 配置文件

五步部署流程

1

连接数据源

在 KTX WebUI 的「数据源」页填写连接字符串，点击「测试连接」验证。当前 release-verified 路径以 MySQL 与 PostgreSQL 为主；StarRocks 属于 R1 P1 gated support，live certification 通过前不作为已验证数据源。建议用只读账号。详见「数据源接入」文档。

2

Schema 扫描

连接成功后点击「扫描 Schema」，KTX 会自动读取所有表和字段，生成语义层 YAML 草稿。

3

完善语义层

在 KTX WebUI「语义层」页为关键字段补充中文描述、定义官方 Measures（指标公式）、配置 Joins。参见「KTX WebUI 使用说明」。

4

运行 Eval

配置完成后在「Eval」页点击「运行」。评测通过后，配置进入服务侧，Agent 可以开始查询。

5

接入 Agent

将 KTX MCP Server 地址添加到 Agent 配置（Claude Code 的 .claude/settings.json，或 Cursor 的 MCP 配置）。

⚠️ 配置上线前必须通过 Eval。Eval 失败时，原有配置仍在服务侧，新配置不会上线。

下一步

完成基础部署后，建议继续完善以下配置：

  • KTX WebUI 使用说明 — 深入学习如何维护语义层、Wiki 和 Join 关系
  • 数据源接入 — 了解各数据库的详细连接配置和只读账号设置
  • 权限与 ACL — 配置 Agent 身份认证和表级访问控制
