Trust

Lucy 是企业数据开放给 Agent 前的可信网关。

智能系统不能只靠“看起来合理”。Lucy 通过 semantic layer、eval、quiz、fallback provenance 和 drift 状态机，在数据被 Agent 消费之前校验口径、路径、边界与结果。

可信链路

Semantic Layer

先用标准指标和 join 路径，减少同名指标多口径。

Eval

机器测 Agent 是否会按正确 SQL 结构、measure lineage 和结果断言回答。

Quiz

人类测业务团队是否理解正确口径，避免只让机器懂。

Fallback Provenance

SL 不覆盖时，记录 raw SQL fallback 的原因、假设和 trace。

Data Drift

区分数据变化、schema 变化、逻辑回归和工具错误，避免把正常漂移误判为模型失败。

组织价值

Skill 固化分析主权

Skill 把资深分析师、财务负责人和业务专家的判断路径沉淀为 Agent 可重复调用的分析肌肉记忆，形成通用模型无法替代的组织智能资产。

Runner 构成免疫系统

Runner 不只是 pass/fail 检查，而是把异常分诊为 data_drift、schema_drift、logic_regression 或 tool_error，并判断关联 Quiz 是否 stale。
