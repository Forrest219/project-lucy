Lucy 帮助文档中心

欢迎使用 Lucy 帮助文档中心。Lucy 是企业数据资产面向 AI Agent 的可信网关——它不直接回答问题，而是让你已经在用的 Agent（如 Claude Code / Codex）安全、准确地访问企业数据。无论你是业务使用者、BI 管理员，还是集成开发者，这里都有你需要的指引。
