User guide

Lucy 帮你在会议里拿到可信、可追问的数据答案。

当销售、运营、财务和管理层对同一个数字各说各话时，Lucy 会优先按企业官方数据标准字典回答，并把口径、限制和数据基准截止时间讲清楚。

Lucy 的使用原则

把问题说成会议决策

不要只问“查一下销售额”。更好的问法是：下周经营会上要讨论区域资源倾斜，请比较最近 4 年各区域销售额和利润率，指出最需要复盘的区域。

让答案自己带上防伪标识

Lucy 的价值不只是给数字，还要说明使用了哪些标准业务指标、哪些筛选条件、数据基准截止到什么时候、有没有走字典外安全探索。

建议路径：首次用户先读《5 分钟理解 Lucy》和《常见任务流》；管理者和数据负责人再读《可信机制》和《Lucy 产品介绍》。
