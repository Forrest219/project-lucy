风险与安全

关键风险与安全边界需在上线前确认。

安全控制边界

  • Token、role、connection、table/view、tool 形成硬约束。
  • 审计记录 MCP 调用、allow/deny、数据来源和时间戳。
  • 配置文件约 30 秒生效；Kill Switch 需作为上线前专项补齐项。

FineReport 落地风险

  • 单元格公式、模板 SQL、参数和权限规则需完整提供。
  • 跨源拼接需先汇聚为单库单表/视图后接入 MCP。
  • 标杆测试用例以 FineReport 前端最终渲染数值为准。
上线前风险确认

落地模块

CEO 管理驾驶舱是首个业务落地模块。

输入材料

18 个 CEO 页面、指标口径、数据溯源、验证结论。

资产治理

默认拒绝；只纳入 owner 确认后的表、视图、SQL 和口径。

MCP 服务化

语义层、Wiki、ACL、审计、评测组合交付。

业务验收

以客户确认的 FineReport 前端最终渲染数值做标杆测试用例。

上线路径

边界与验收

边界与验收合并管理，避免预期错位。

R1 包含

  • MCP endpoint 与基础客户端接入。
  • 语义层、Wiki、权限、审计、脚本化 eval。
  • CEO 管理驾驶舱首批主题验证。

R1 不包含

  • WebUI 管理台、自助编辑器、审计看板。
  • Kubernetes、多机高可用、监控告警平台。
  • 秒级 Kill Switch 不纳入当前 R1 交付范围。

平台链路

Docker 启动、MCP initialize、tools/list、sl_read_source、sl_query。

治理链路

授权可访问，越权被拒绝；审计日志可查询或导出。

业务链路

CEO 驾驶舱标杆测试用例与 FineReport 快照在容差内一致。

边界与验收

确认事项

需要 CIO 与数据平台负责人确认的事项。

数据访问路径

是否可通过网络策略确保 Agent 不直连数据库，只通过 Data Agent MCP 访问数据。

资产准入

是否提供 owner、只读账号、白名单、敏感分级和脱敏要求。

FineReport 材料

是否提供 .cpt/.frm、内置 SQL、单元格公式、参数、权限规则。

Agent 客户端范围

已验收 Claude Code / Codex / Cursor / Openclaw / Hermes；确认最终做数据消费的客户端清单，未列入的客户端需补充验收。

结论

建议结论：R1 可以作为受控范围试点，但必须先锁定资产与验收值。
