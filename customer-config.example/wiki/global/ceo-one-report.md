# CEO One Report Business Context

CEO one-report cases must cite the business metric definition before answering.
Metric values come from `ceo_metric_snapshot` unless a case explicitly names a
more detailed fact table.

Ratio metrics must be recomputed from numerator and denominator when those fields
are available. Do not average row-level ratios.
