# 回答骨架

对话与口径见 [prose.md](prose.md)。表内见 [business-style.md](business-style.md)。数字换成当次查询结果。下面每段里，表是商务层，表外句子是对话层或口径层。

## 排名

```text
按 `category` 作为「产品线」，2026 年利润降序排名如下：

| 排名 | 产品线 | 利润 | 销售额 | 利润率 |
| ---: | --- | ---: | ---: | ---: |
| 1 | 技术 | 368,547.11 | 1,975,038.96 | 18.66% |
| 2 | 办公用品 | 302,636.93 | 1,840,306.90 | 16.44% |
| 3 | 家具 | 24,281.98 | 1,590,018.74 | 1.53% |

口径：SUM(profit) 排名，SUM(sales) 销售额，SUM(profit)/NULLIF(SUM(sales),0) 利润率；过滤 is_deleted = 0，年份为 YEAR(order_date)=2026。

如果你这里的「产品线」指的是更细的 `sub_category`，我可以按子类目再跑一版。
```

## 单值

无表。数字在导语。

```text
2026 年利润为 695,466.02。

口径：SUM(profit)；过滤 is_deleted = 0，年份为 YEAR(order_date)=2026。
```

## 两年对比

```text
2025 年与 2026 年利润对比如下：

| 年份 | 利润 | 销售额 | 利润率 |
| --- | ---: | ---: | ---: |
| 2025 | 612,004.30 | 4,880,120.00 | 12.54% |
| 2026 | 695,466.02 | 5,405,364.60 | 12.87% |

口径：SUM(profit) 利润，SUM(sales) 销售额，SUM(profit)/NULLIF(SUM(sales),0) 利润率；过滤 is_deleted = 0，年份为 YEAR(order_date) IN (2025, 2026)。
```

## 前 10

截断写在表外。

```text
按 `sub_category` 作为「子类目」，2026 年销售额降序前 10 如下：

| 排名 | 子类目 | 销售额 |
| ---: | --- | ---: |
| 1 | 电话 | 328,120.40 |

口径：SUM(sales) 销售额；过滤 is_deleted = 0，年份为 YEAR(order_date)=2026。表内为前 10，共 17 个子类目。
```

## 无记录

不造表。

```text
2026 年没有可计入的订单行。

口径：SUM(profit)；过滤 is_deleted = 0，年份为 YEAR(order_date)=2026。当前查询返回 0 行。
```

## 推算行

备注列只在有例外时出现，异常行用固定短语，其余行留空。

```text
按月份，2026 年利润如下：

| 月份 | 利润 | 备注 |
| --- | ---: | --- |
| 2026-01 | 41,220.00 | |
| 2026-02 | 18,640.15 | 按累计差额推算 |

口径：SUM(profit) 利润；过滤 is_deleted = 0，年份为 YEAR(order_date)=2026。2026-02 无单期事实行，由相邻累计值相减得到。
```

## 合计

用户要总额时，表末加 `合计`，排名留空。

```text
2026 年各产品线利润如下：

| 产品线 | 利润 | 销售额 |
| --- | ---: | ---: |
| 技术 | 368,547.11 | 1,975,038.96 |
| 办公用品 | 302,636.93 | 1,840,306.90 |
| 家具 | 24,281.98 | 1,590,018.74 |
| 合计 | 695,466.02 | 5,405,364.60 |

口径：SUM(profit) 利润，SUM(sales) 销售额；过滤 is_deleted = 0，年份为 YEAR(order_date)=2026。
```
