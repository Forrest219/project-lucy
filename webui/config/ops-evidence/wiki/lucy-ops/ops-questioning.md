# 运维问数连接（lucy-ops）

只读连接，指向当前实例的审计热库。暴露两张视图：

| 视图 | 一行 | 用途 |
|---|---|---|
| `ops_calls` | 一次工具调用 | 调用流水、活跃 Agent、按工具/结果的汇总 |
| `ops_call_tables` | 一次调用 × 一个来源表 | 哪张表被问得最多、某张表上谁被拒绝与生成 SQL |

两张视图覆盖**同一个事件集合**：默认用量（协议事件与默认视图排除的评测探针不计
入），再排除本连接自己的追问（按整次调用排除，不留残余行）。

## 口径

**本连接只回答活跃 Agent。**

- **活跃 Agent**：窗口内 `ops_calls.agent_id` 的去重。这是本连接唯一的**人口**。
- **`token_label`**：同一 Agent 内的标签，不是凭据身份。两个 Agent 可以用同一个
  标签；同一 Agent 删除后重建同名标签也无法区分前后两枚 Token。可以按标签过滤
  明细，但**不把 `token_label` 去重称为业务活跃 Token**（也禁止称为活跃用户或
  任何 Token 人口）。
- **业务活跃 Token**：以**使用概况**为准，本连接不回答。
- **访问账户不在本连接**；页面访问也不在本连接，`ui_page_views` 不在本连接
  范围内。需要时指向使用概况的界面使用视图。
- **`call_day` 是 UTC 日历日**（`ts` 的 UTC 日历日，SQLite 的 `date(ts)`）。问
  「过去 7 天」时过滤这 7 个 UTC 日，并在回答里写明窗口是 UTC。
- **生成 SQL**（`generated_sql`）：高基数属性，只在已按表、Agent、结果或
  `request_id` 过滤之后取出，**生成 SQL 不作为默认分组**。

## 指标

| 指标 | 含义 |
|---|---|
| `call_count` | 调用次数 |
| `denied_count` | 被拒绝的调用次数 |
| `error_count` | 出错的调用次数 |
| `total_duration_ms` | 耗时合计（毫秒） |

## 不在本连接范围

- 业务活跃 Token 人口、访问账户、页面访问。
- 三张示例表（订单、人员、退货）的业务口径问题——**退货口径仍以 Docker demo
  已有 Wiki 为准**，本篇不覆盖。
