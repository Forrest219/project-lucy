## 目标

- 保证跨页面视觉与交互的一致性。
- 降低新增功能的 UI 设计分歧与返工成本。
- 让设计决策可审计、可测试、可治理。

## 核心原则

1. **一致优先**：同一语义用同一视觉表达（颜色、层级、尺寸、状态）。
2. **层级清晰**：主次路径必须可一眼分辨，且不可混用误导性显著性。
3. **可操作性**：任何可交互元素必须有清晰 affordance（hover/focus/disabled）。
4. **可读与可达**：文本可读、颜色对比达标、键盘可用、屏幕阅读器可理解。
5. **演进可控**：新增模式必须先补规范再落代码，避免“先写后补”失控。

## 规范分层

- **Foundations**：颜色、间距、网格、排版等底层 token 和节奏
- **Components**：按钮、表格、输入、卡片、抽屉、徽标等组件规范
- **Patterns**：页面级布局与交互模式（列表、详情、配置、空态、错误态）
- **Governance**：规范变更流程、验收要求、回归策略

## 验收基线

- 有规范条目的 UI 改动必须引用对应章节。
- 无规范条目的 UI 改动必须先登记临时决策。
- 回归测试至少覆盖：视觉层级、交互状态、术语一致性、翻译防御。
