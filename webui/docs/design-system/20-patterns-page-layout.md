## 1. 目的

定义 Lucy WebUI 页面层的通用布局模式，避免每个页面单独定义结构，导致导航、操作区、信息密度和响应式行为不一致。

## 2. 标准页面结构

默认页面由以下区域组成：

1. Page Header（标题、简述、主操作）
2. Summary Region（核心状态/统计）
3. Primary Workspace（主任务内容）
4. Secondary Region（辅助信息、提示、历史）

要求：

- 主任务内容必须稳定落在 Primary Workspace，不得被次要操作挤占首屏。
- 主操作区不承载低价值信息；低价值状态应放入 summary 或 description。
- 二级区域默认可折叠或弱化，不与主任务争抢层级。
- Summary Region 若使用顶部 KPI 指标卡，必须遵循 `12-components-metric-card.md` / Spec 103（Connections 基准、每卡 ⓘ）；网格列数允许 3 / 4 / 2×4，但卡内模板不得漂移。`/overview` 不再使用 Ops Metric Row 快照卡（Spec 142）。

## 3. 列表/工作台页模式

适用：`/connections`、`/catalog`、`/wiki` 等高密度操作页面。

- 顶部：页面身份 + 全局动作（数量可控）
- 中部：筛选/分组工具条
- 主体：数据网格或卡片列表（可滚动）
- 辅助：抽屉/详情区用于次任务，不替代主流程

约束：

- 表格页不得在同一屏引入第二个“等价侧栏导航”。
- 行内动作与页级动作层级分离；行内动作为弱层级。

## 4. 概览页模式

适用：`/overview`。

- Header：一句描述 + 刷新操作
- 上段：系统状态（一句摘要；不可用才 Alert）
- 中段：待处理事项（唯一行动队列）
- 下段：MCP 接入（工具性，弱权重）

约束：

- 概览页以“诊断和引导下一步”为目标，不承载深度编辑工作流。
- 并列入口动作默认同级，避免人为制造主次误导。

## 5. 配置页模式

适用：角色配置、连接配置、规则配置等高责任页面。

- 主体优先展示“当前可服务状态 + 风险状态 + 审阅入口”
- 技术细节（raw scope/tool list）默认放在详情层，而非首页噪音输出

## 6. 响应式与可达性

- 断点至少覆盖 `>=1440`、`1280-1439`、`1024-1279`、`<1024`
- 小屏优先保证：主任务可达、主操作可见、滚动路径明确
- 页面中所有可交互区域必须可键盘访问，焦点顺序符合视觉阅读顺序
- 当视口小于全局最小可读宽度时，页面保持桌面布局并改为横向滚动承载，不进入移动端重排
- 不得通过“隐藏主操作/关键字段”来伪造适配结果

## 7. 验收清单（页面级）

- 页面是否只存在一个清晰的主任务区域？
- 主操作是否与次要信息解耦？
- 是否复用了已有布局模式而非新造结构？
- 断点下是否仍保持操作可达和阅读顺序？
- 是否符合 `docs/ui-ux-feedback/README.md` 的跨页面治理规则？

## 8. 页面分区异步加载（AsyncRegion）

升格自 TD-174-01（Spec 174，已 Implemented）。适用 `/connections`、`/catalog`、`/overview`、Agent 列表的数据区；新增页面使用须先在 Spec 登记。

- 占位立即出现、固定尺寸、无动画；120 ms 后才出现「正在加载…」。
- `aria-busy` 只设在对应区域。
- 错误留在依赖模块并提供「重试」。
- 已有数据的后台刷新不替换主内容。
- 占位不得复用真实内容的 `data-testid`。
- 沿用既有 token，不改变 Spec 142 的布局层级。

## 9. 发布工作台三栏与宽确认侧栏

升格自 TD-20261030-01（Spec `lucy-20261030-publish-workbench-three-column-spec` §4／§4.5，功能合同已收口）。仅用于 `/publish/workbench`。

- 三栏为「待发布变更 / 生效准备 / 最近发布」，12 列网格下初始 4/5/3。
- 使用本页专属 class `.pl-publish-workbench-layout`，**禁止修改共享的 `.pl-review-layout`**。
- 宽确认侧栏宽度由组件内联给出（目标 880px、最大 960px、不超过视口宽减 48px），**禁止修改共享的 `.pl-drawer-panel`**。
- 确认侧栏页头与页脚固定在面板内，正文是唯一纵向滚动区（`min-height: 0` + `overflow-y: auto`）。
- 不为多显示几列压缩正文字号，不套用高密度 Data Grid 的字号压缩。
- 完整表名与原因默认可见、可换行，不能只依赖 hover。
- 确认列表不得静默截断（禁止 `slice(0, 8)`）；搜索与折叠只过滤展示，不得缩小提交范围。

## 10. 侧栏底部账户菜单

升格自 TD-188-01（Spec 188，已实现）。

- 账户信息、系统手册、退出登录合并为单一入口；单行低干扰按钮。
- Portal 浮层向上展开，宽 288px，视口边距与入口间距 8px；沿用语义色、圆角与阴影。
- 高度受可用空间约束，内部滚动；完整键盘访问，关闭后焦点归还入口。
- 开放模式及未登录时保留独立手册入口。
- 退出登录期间禁用入口防重复提交；失败显示错误并恢复可操作。
