# 登录页安静表单

| 元数据 | 内容 |
|---|---|
| 文档类型 | Plan |
| 版本 | v1.0 |
| 撰写日期 | 2026-10-19 |
| 适用范围 | `/login` 日常登录与创建首个所有者 |
| 对照 | DeepSeek 开放平台桌面登录页 `https://platform.deepseek.com/sign_in` |

## 决定

日常登录页只保留产品名和一张表单。「登录」只出现在提交按钮上。字段名继续使用「登录账户」和「密码」。创建首个所有者时保留标题「创建首个所有者」，按钮仍为「创建并登录」。

不改成深色分栏，不加手机号、扫码或注册。登录账户 id、本地密码和会话不变。

## 改动

1. 日常登录去掉标题「登录」。引导创建首个所有者时保留标题。
2. 「登录账户」占位改为示例 `例：lucy`。字段名保留。
3. 输入框加高到 44px。提交按钮与字段拉开距离，帮助链接用更小的弱字色，仍指向 `/help?section=admin-break-glass`。
4. 密码框增加显示/隐藏，按钮文案为「显示密码」和「隐藏密码」。

## 验证

- 组件测试：日常登录没有标题「登录」；有「登录账户」「密码」和按钮「登录」；占位为 `例：lucy`；切换后密码可见。引导页仍有标题「创建首个所有者」。
- 浏览器：打开登录页，确认标题已去掉、占位为示例、密码可切换显示，错误密码仍停在登录页并提示失败。
