# 投放账户漏斗口径与复盘 Playbook

> 适用：`dataforai.ad_account_daily`（投放账户日级漏斗）。  
> 时间范围以表内 `date` 的 min/max 为准；**相对「最近」锚定 max(date)，不用系统今天**。  
> 配置与回答中不要写死起止日（数据会更新）。

## 何时使用

用户询问以下内容时，首选本页：

- 花费、预约、获客成本 / CPA、渠道或账户效率对比
- 漏斗质量（有效 / 优质 / 良好 / 预约）、优质率
- 周度投放复盘、渠道预算再分配、问题账户诊断
- 「自运营 vs 代理」对比

## 表角色与粒度

| 项 | 说明 |
|---|---|
| 物理表 / source | `dataforai.ad_account_daily` |
| 粒度 | `account_name + date`（账户 × 日） |
| 渠道枚举 | 巨量引擎 / 腾讯广告 / 百度营销 / 小红书 / 快手磁力引擎 |
| 客户等级 | A级 / B级 / C级 |
| 约束 | 每个账户固定对应一个渠道、一个客户等级；调渠道预算 = 调对应账户花费 |

「自运营 / 代理」**无独立字段**，从 `account_name` 是否包含「自运营」「代理」识别。

## 漏斗与质量规则

顺序：**有效客户 → 优质客户 → 良好客户 → 预约**  

应满足：`valid_customers ≥ quality_customers ≥ good_customers ≥ appointments`。  
若出现倒挂，视为数据质量异常，需指出异常行/账户。

## 核心口径（必须 SUM/SUM）

| 指标 | 公式 | 语义 measure |
|---|---|---|
| 预约 CPA（默认获客成本） | 花费合计 ÷ 预约合计 | `预约CPA` |
| 有效客户 CPA | 花费合计 ÷ 有效客户合计 | `有效客户CPA` |
| 优质客户 CPA | 花费合计 ÷ 优质客户合计 | `优质客户CPA` |
| 良好客户 CPA | 花费合计 ÷ 良好客户合计 | `良好客户CPA` |
| 优质率 | 优质客户合计 ÷ 有效客户合计 | `优质率` |
| 良好转化率 | 良好客户合计 ÷ 优质客户合计 | `良好转化率` |
| 预约转化率 | 预约合计 ÷ 良好客户合计 | `预约转化率` |
| 有效→预约转化率 | 预约合计 ÷ 有效客户合计 | `有效到预约转化率` |
| 花费占比 | 某渠道/账户花费 ÷ 总体花费 | 现场计算 |
| 预约占比 | 某渠道/账户预约 ÷ 总体预约 | 现场计算 |

**禁止**：先按日算 CPA/比率再平均（`AVG(日CPA)`）。

## 同义词

| 用户说法 | 默认处理 |
|---|---|
| CPA / 获客成本 / 预约成本 | 预约 CPA，除非明确说有效客户 CPA |
| 效率 / 性价比 | 优先预约 CPA（越低越好），辅看优质率 |
| 产出 / 结果 | 优先预约量，辅看有效/优质客户 |
| 客资质量 | 优先优质率 |
| 最近 / 本周 / 近 N 天 | 锚定 max(date)；模糊说法先澄清 |

## 时间与澄清策略

1. 需要时先查 `min(date)` / `max(date)`。  
2. 用户只说「最近怎么样」→ **先澄清**窗口（如末日近 7 天 vs 近 30 天）；用户说「按默认」→ 末日近 7 天，并在回答开头写明实际日期。  
3. 用户已给出明确月份/季度/起止日 → 直接分析。  
4. 业务对比优先近周 / 近月 / 上半年；勿默认跳到很久以前的完整年。

## 技能工作流（AskTable 技能 → Lucy Wiki）

### A. 周度投放复盘

1. 汇总本周与上周：总花费、总预约、预约 CPA；算环比  
2. 按渠道、账户拆解；指出花费贡献最高、预约 CPA 最差者  
3. 找 1～2 个重点跟进账户（优先：花费高于中位且预约 CPA 高于整体；严格规则无命中时可放宽）  
4. 给出下周加量 / 减量 / 观察建议，须引用本周数字  

输出：本周概览 → 环比 → 渠道与账户 → 问题账户 → 下周动作。

### B. 渠道预算再分配

目标：总花费大致不变，提升总预约。

1. 按渠道汇总花费、预约、占比、预约 CPA、优质率  
2. 诊断错配：花费占比明显高于预约占比或 CPA 偏高 →「可减」；反之「可加」  
3. 给出平移方案（从哪到哪、幅度、优先账户）  
4. 估算：`预约净增量 ≈ 挪入金额÷目标渠道预约CPA − 挪出金额÷来源渠道预约CPA`  
5. 写明假设与至少 2 条失效风险  

未指定时间时：优先「数据末日所在年的上半年」。

### C. 问题账户诊断

判定（须写进回答）：

- 主规则：花费 ≥ 全账户花费中位数，且预约 CPA ≥ 全账户预约 CPA 中位数  
- 命中过少：放宽为花费前 40% 且有效→预约转化率后 40%；仍过少则补充业务视角（CPA 明显高于整体且优质率偏低），并说明放宽原因  

输出：判定规则 → 问题账户表 → 漏斗定位 → 观察/优化/缩量动作 → 约 2 周验收指标。

## 回答策略

- 结论先行，数字准确；比率类误差目标 ≤1%。  
- 口径题：先给公式，再说明分子分母字段。  
- 若用户当场指定口径与本手册冲突，以用户当场为准并声明。  
- 方案题验净值公式自洽，不锁死示例幅度。

## 常见错误（反模式）

1. 用系统「今天」代替 `max(date)`  
2. 对日 CPA 再平均  
3. 把「获客成本」答成有效客户 CPA（未声明时）  
4. 假设账户可换渠道  
5. 默认拉完整历史年做对比
